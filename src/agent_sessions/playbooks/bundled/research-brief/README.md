# Research brief

Define a question, draft an evidence-backed answer, review it independently and ask the operator
to accept it. The review can return to the draft at most **three times** before the intended flow
asks the operator to decide.

Open **Library → Playbooks → Research brief → Duplicate to local → Edit playbook**. Set the
question and audience declarations, adapt the evidence criteria, and choose available agents
and models. Codex and Claude are example references; an unavailable agent remains unresolved
until you replace it. Keep the review in a different session from the drafter.

The checklist requires sources that support material claims, explicit uncertainty and contrary
evidence, an independent verdict, and operator acceptance. A citation alone is not evidence that
a claim is supported: the reviewer must check what the source actually says.

**Available now:** browse, duplicate, edit and save. Saving does not execute the flow. Automatic
step dispatch and bounded revision transitions are still being implemented. This example has no
connections, credentials, publishing actions, scripts or project-file materials. Accepting the
brief does not send it anywhere.
