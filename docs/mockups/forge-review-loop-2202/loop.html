3 · CONSENT — SERVER LINES, ONE PER SCOPE FIELD
Turn on “Review loop · example-org/shop”?
  • Starts when Forgejo sends a signed event for example-org/shop
  • Reviews issues (opened, edited) and pull requests (opened, reopened, pushed; drafts skipped)
  • Starts Shop Reviewer v3 (opencode · mimo-v2.6-pro · effort high) in project shop (/srv/work/shop)
  • Trusts verdicts only from shop-reviewer-bot
  • Sends the verdict to the API session that opened the item, if it is in project shop and on the pull request's branch; a terminal session gets nothing and you are notified
  • Accepts one verdict per review it started, for the revision it reviewed; anything else is ignored and recorded
  • At most 4 reviews per pull request, 5 per issue, over its whole life; then one notification
  • Reads each item's current revision from your forge (Settings → Forge) before it starts a review or accepts a verdict; if it can't, nothing happens
  • Never posts, merges or labels on the forge
  • At most 48 runs a day · pause after 3 failures · no expiry
