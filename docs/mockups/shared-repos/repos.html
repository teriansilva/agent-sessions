Shared artifact repositories

Library → Artifacts gains a REPOSITORIES tab. A repository lives on ONE BattleLab (its host). The host's operator gives paired instances (Settings → Peers) access to read it or to add to it. Every item is an immutable artifact revision, so a copy is what you get, never a live folder. Instance names here are the labels you gave your peers.
